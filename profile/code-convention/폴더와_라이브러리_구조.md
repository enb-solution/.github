# 📁 프론트엔드 & 백엔드 폴더 및 라이브러리 구조

## 🧩 Frontend 구조

```plaintext
project-root/
├── public/        # 정적 리소스 (이미지, 폰트, 아이콘 등)
├── src/
│   ├── api/           # API 요청 함수 정의 (axios 기반)
│   ├── components/    # 공통 UI 컴포넌트 (재사용 가능)
│   ├── constants/     # 상수 정의
│   ├── hooks/         # 커스텀 훅 (API 호출, 상태 처리, 로직 분리)
│   ├── pages/         # 주요 비즈니스 페이지 (라우팅 단위)
│   ├── providers/     # 전역 Provider 모음
│   ├── routes/        # 라우팅 설정 정의 (React Router 등)
│   ├── store/         # 상태 관리(store) 정의 (Zustand 사용)
│   ├── utils/         # 공통 유틸 함수 (format, 계산 등)
│   └── index.css      # 전역 스타일 (Tailwind 등)
```

### ✅ 주요 라이브러리

| 항목             | 도구/라이브러리          |
| ---------------- | ------------------------ |
| 서버 라이브러리  | React Query v5           |
| 상태 라이브러리  | Zustand                  |
| UI 라이브러리    | Tailwind CSS, Ant Design |
| Chart 라이브러리 | ECharts                  |
| HTTP 통신        | Axios                    |
| 빌드 도구        | Vite                     |

## ⚙️ Backend 구조

### 기본 구조 (Controller → Service → Repository)

```plaintext
src/
├── {domain}/
│   ├── {domain}.controller.ts   # 요청 처리 (req, res)
│   ├── {domain}.service.ts      # 비즈니스 로직
│   ├── {domain}.repository.ts   # 데이터 접근 (DB 연동)
│   ├── {domain}.module.ts       # 모듈 정의
│   ├── dto/                     # 요청/응답 DTO
│   └── entities/                # 엔티티 정의
```

### MES 적용 구조 (Controller → Usecase → Repository)

```plaintext
src/
├── {domain}/
│   ├── {domain}.controller.ts     # 요청 처리 (req, res)
│   ├── usecases/                  # 단일 비즈니스 동작 단위로 분리
│   │   ├── create-{domain}.usecase.ts
│   │   └── get-{domain}.usecase.ts
│   ├── {domain}.repository.ts     # 데이터 접근 (DB 연동)
│   ├── {domain}.module.ts
│   ├── dto/
│   └── entities/
```

### ✅ 주요 도구 및 라이브러리

| 항목            | 도구/라이브러리       | 비고                                          |
| --------------- | --------------------- | --------------------------------------------- |
| 서버 프레임워크 | Nest.js               | 데코레이터 기반 모듈 구조                     |
| ORM / 쿼리 도구 | Prisma                | DB 연동 방식                                  |
| 인증/인가       | @nestjs/jwt, Passport | JWT 기반 인증                                 |
| HTTP 테스트     | -                     | 별도 작성한 API 문서(api-doc) 기준으로 테스트 |
| 환경 변수 관리  | @nestjs/config        | `.env` 기반, ConfigModule로 관리              |
